# PLAUD議事録Bot（plaud-bot）

PLAUD（AIボイスレコーダー）の録音要約を、LINEワークスやスプレッドシートに自動配信するボット群です。

## ボット一覧

| 名前 | ファイル | いつ動くか | 何をするか |
|---|---|---|---|
| 朝練Bot | `asaren_bot.yml` | 水〜土 10:00（Cron-job.org「朝練Bot」ジョブが起動） | 朝練の録音要約をLINEワークス歯科医師チャンネルに投稿 |
| 軸MTG Bot | `jiku_bot.yml` | 毎週水曜 21:00（Cron-job.org「軸MTG Bot」ジョブが起動） | 軸ミーティングの議事録要約をLINEワークス「軸」チャンネルに投稿。⚠️**2026年8月中は軸チャンネルへ投稿せず院長DMのみ**（村田さんの卒業に伴う一時措置。2026-09-01から自動で元に戻る） |
| 面談記録シートBot | `mendan_sheets.yml` | 月〜土 21:00（apotoolのコンサル同期から連鎖起動） | PLAUDの「面談（名前）」録音を面談記録スプレッドシートにスタッフ別・時系列で自動追記 |
| PLAUD配信Bot | `mendan_sheets.yml` 内の `share_bot.py` | 月〜土 21:00（面談記録シートBotと同じ実行内） | 録音タイトルで振り分けてPLAUD要約リンクを配信：面談（桑野）→桑野さんDM／面談（斉藤）→斉藤さんDM／事務MTG→事務ルーム。木曜に事務MTG・金曜に面談（桑野）の録音が無ければ院長DMへアラート |
| 軸MTG 後追い追記 | `jiku_backfill.yml` | 手動のみ | 軸MTG Botが拾えなかった回を「軸MTG要約集」Googleドキュメントへ後から追記する。LINEワークスへは投稿しない |
| チャンネルID一覧 | `list_channels.yml` | 手動のみ | Botが参加しているトークルームのIDをログに出力（新ルーム招待後のID特定用・管理ツール） |

## 軸MTGがドキュメントに入らなかったとき

軸MTG Bot は「実行した日の、院長のPLAUDにある軸MTG」しか拾えません。次の2つは取りこぼします。

| 取りこぼす理由 | 後追い追記の入力 |
|---|---|
| 院長が欠席し、録音が他の人のPLAUDアカウントにある | `share_url` に共有URLを入れる |
| Botの実行日と録音日がずれた（開催曜日の変更など） | `target_date` に録音日（YYYY-MM-DD）を入れる |

Actionsタブ →「軸MTG 後追い追記（手動）」→ Run workflow で実行。すでに入っている回は自動でスキップします。

## エラーが起きたら

- GitHubの「Actions」タブで❌赤印の実行を確認
- Claude Codeに「朝練Botのログを見て」などと頼めば調査します
